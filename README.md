# First Java CRUD

A simple Java CRUD application for managing students.

## Features

- Create a student
- Read students
- Update student information
- Delete a student

## Requirements

- Java 17 or newer

## How to run

Compile:

```bash
javac -d out src/main/java/com/university/crud/Main.java
```

Run:

```bash
java -cp out com.university.crud.Main
```

## Note

Student records are stored in memory and are cleared when the application exits.
