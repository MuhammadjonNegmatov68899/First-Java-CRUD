# First Java CRUD

A simple Java CRUD application for managing students.

## Features

- Create a student
- Read all students
- Update student information
- Delete a student

## Requirements

- Java 25 or compatible version

## How to run

Compile the application:

```bash
javac -d out src/main/java/com/university/crud/Main.java

Run the application:

java -cp out com.university.crud.Main

Technologies
- Java
- Git
- GitHub
```
